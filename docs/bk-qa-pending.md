# 병관(BK) 담당 기능 — 아직 확인 못 한 QA 목록

로컬·PC 브라우저로는 확인이 어려워서 **나중에 꼭 확인할 것**만 모아 둔 목록.
확인하면 `[ ]` → `[x]`로 바꾸고 날짜·기기를 적는다. 문제가 있으면 아래 "발견한 문제"에 적는다.

## 실제 휴대폰에서 확인할 것 (배포 사이트 https://aleph-capstone.vercel.app)

| 확인 | 기능 | 확인 방법 | 기대 결과 | 기기 · 날짜 |
|---|---|---|---|---|
| [ ] | 📸 인증샷 **공유하기** (11/20 추가) | 휴대폰으로 접속 → 오른쪽 위 📸 인증샷 → 미리보기의 [공유하기] | 카톡·인스타 등 공유 창이 뜨고, 사진(JPG)이 첨부된다. [공유하기]가 없으면 [사진 저장]으로 갤러리/다운로드에 저장된다 | 아이폰 사파리: / 갤럭시 크롬: |
| [ ] | 모바일 조작 (조이스틱·E·점프·달리기) | 왼쪽 조이스틱으로 걷기, E 버튼으로 루미 대화, 달리기 켜고 끄기 | 손을 떼면 멈춤, 대화창이 열리면 조작 버튼이 숨음, 화면이 확대·스크롤되지 않음 | |
| [ ] | 첫 접속 로딩 화면 | 휴대폰 데이터(와이파이 끄고)로 처음 접속 | 진행률이 올라가고, 끝나면 부드럽게 사라짐 (25초 넘으면 자동으로 닫힘) | |
| [ ] | 루미 튜토리얼 안내 띠 | 시크릿 탭으로 처음 접속 | 안내 띠가 조이스틱·버튼 위에 떠서 가리지 않음, "E 버튼"으로 안내 | |
| [ ] | 미니맵·코스 안내 위치 | 루미 코스 받고 걷기 | 미니맵(오른쪽 위)·코스 안내(위 가운데)·메뉴 버튼이 서로 크게 겹치지 않음 | |

## 귀로 들어 봐야 하는 것 (자동 테스트로는 소리가 "나는지"만 확인함)

| 확인 | 기능 | 확인 방법 | 기대 결과 | 기기 · 날짜 |
|---|---|---|---|---|
| [ ] | 🔊 효과음 (11/20 추가) | 화면을 한 번 클릭한 뒤 걷기·달리기, 스탬프 찍기, 루미 코스 도착·완주, 📸 인증샷, 소원 분수 근처 가기 | 발소리(달리면 빠르게)·"쾅"·"띵"·"빠라밤"·"찰칵"·물소리가 들리고, 너무 크거나 겹쳐서 시끄럽지 않음 | PC: / 휴대폰: |
| [ ] | 🔊/🔇 음소거 | 오른쪽 위 🔊 누르기 → 새로고침 | 🔇로 바뀌고 모든 소리가 꺼짐, 새로고침해도 유지 | |
| [ ] | 휴대폰 소리 | 휴대폰으로 접속 → 화면 한 번 터치 → 걷기 | 첫 터치 뒤부터 소리가 남 (무음 모드면 안 나는 게 정상) | |

## 시간이 지나야 확인할 수 있는 것

| 확인 | 기능 | 확인 방법 | 기대 결과 |
|---|---|---|---|
| [ ] | AI 서버 미리 깨우기 (Render 무료 서버) | **15분 이상 아무도 안 쓴 뒤** 배포 사이트 접속 → 로딩이 끝나면 바로 루미에게 말 걸기 | 대답이 몇 초 안에 옴 (예전엔 첫 대답이 약 50초) |
| [ ] | 오늘의 코스 날짜 바뀜 | 다음 날(한국 시간 0시 이후) 🎁 오늘의 코스 | 요일 테마가 바뀌고, 오늘의 코스 배지를 새 날짜로 또 받을 수 있음 |
