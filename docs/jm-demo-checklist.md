## 애니 구역 시연 동선 (약 3분)

> 11/25 오후부터 애니 구역 전체가 「센과 치히로의 행방불명」 배경 마을이다 (영화 순서: 터널 → 풀밭 → 징검돌 → 돌계단 → 음식점 거리 → 붉은 다리 → 온천장). 다른 작품 명장면 ①~④는 음식점 거리 골목 끝 흰 회벽 마당 (DB에 `20261129120000_jm_canal_village.sql` 적용 필요)

1. 입구: 바랜 붉은 회벽 탑 아래 작은 아치 → 어두운 굴 → 색유리 대합실 → 풀밭 언덕 → 마른 강 징검돌 → 긴 돌계단 → 마을 문 「灯籠横丁」
2. 음식점 거리 큰길: 붉은 등 줄·간판(일본어 밑에 작게 한국어). 북쪽 서쪽 「組紐 結び屋」 옆 골목 → 명장면 ② 「너의 이름은.」 마당. 계단을 올라 위 마당에서 **스탬프 찍기**
   - 같은 작품 가게 「組紐 結び屋」 쿠폰이 함께 나오는지 확인 → 쿠폰함
3. **같은 스탬프를 한 번 더** 찍어 "이미 받은 스탬프예요"가 뜨는지 확인 (서버가 중복을 막음 — DB unique 제약)
4. 큰길 끝 → 둥근 붉은 다리 위에서 명장면 ⑤ 「센과 치히로의 행방불명」 스탬프 (다리 밑은 바다 위 철길과 전차)
5. 시간이 남으면 온천장 「湯灯屋」: 1층 로비 → 서쪽 「ゆ」 문 → 번대·약탕 패 → 탕 / 동쪽 계단 → 2~4층 장지문 연회장 → 5층 금빛 문 안 주인 집무실 / 앞마당 서쪽 바깥 계단 → 물가 보일러실(약초 서랍장·화덕)
   - 엘리베이터 칸은 있지만 순간 이동은 병관 님 워프 파일에 `exact` 지원이 들어가야 움직임 (그 전엔 "운행 준비 중" 안내)
