## 애니 구역 시연 동선 (약 3분)

> 11/25 저녁 기준. 애니 구역 전체가 「센과 치히로의 행방불명」 배경 마을 (터널 → 풀밭 → 넓은 강 징검돌 → 넓은 돌계단 → 계단식 음식점 거리 → 붉은 다리 → 바다 위 섬 온천장). 다른 작품 명장면 ①~④는 담 없이 거리 사이 빈터 (DB에 `20261129120000_jm_canal_village.sql` 적용 필요)

1. 입구: 구역에 들어서자마자 큰 붉은 탑 아래 아치(양옆 작은 막힌 아치, 이끼 석상) → 굴 → 대합실 → 풀밭 쪽 시계탑 → 강 징검돌 → 넓은 돌계단·큰 소나무 → 마을 문 「灯籠横丁」
2. 큰길 북쪽 단(계단) → 서쪽 「組紐 結び屋」 옆 골목 계단으로 내려가 명장면 ② 「너의 이름은.」 산 위 신체 사당. 이끼 돌계단을 올라 **스탬프 찍기** → 같은 작품 가게 쿠폰 확인 → 쿠폰함
3. **같은 스탬프를 한 번 더** 찍어 "이미 받은 스탬프예요" 확인 (DB unique 제약)
4. 다리 앞 광장 → (시간 있으면 동쪽 계단으로 꽃 덤불 정원) → 붉은 다리 위 명장면 ⑤ 스탬프
5. 섬 온천장: 1층 로비 → 서쪽 「ゆ」 문 → 번대·탕 / 2~4층 장지문 연회장 / 5층 모자이크 방 → 큰 문 → 집무실·아기 방 / 로비 앞쪽 동쪽 구석 작은 문 → 지하 보일러실 / 섬 서쪽 바깥 계단 → 선착장 → 정거장 부두에서 전차 안
   - 엘리베이터: 가운데 누각 = 손님용(1~4층), 동쪽 뒤 구석 = 직원용(보일러실·5층 집무실). 칸 안 레버 앞에서 E → W/S로 층 고르기 → E 출발
